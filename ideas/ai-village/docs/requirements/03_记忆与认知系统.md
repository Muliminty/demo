# 3. 记忆与认知系统 (Memory & Cognition System)

## 3.1 分层存储架构
为了让 AI 角色在长时间运行中既有关联记忆又控制 Token 消耗，角色的记忆分为三个独立的存储层级：
*   **感官层 (Sensory Memory) / 短期工作区**：
    *   **触发方式**：即时发生的琐事，例如“刚刚走过了谁旁边”、“现在的天气是下雨”。
    *   **存储形式**：以纯文本队列保存在内存中，限制长度（如只保留最近 10 条）。
    *   **作用**：作为角色下一次对话或行动的直接上下文（Context）。
*   **深度记忆 (Core Memory) / 向量数据库**：
    *   **触发方式**：人生重大事件（如：结婚、生子、至亲去世、收到上帝指名道姓的神谕）。
    *   **存储形式**：通过 Embedding 模型将文本转化为向量，永久存入向量数据库（如 ChromaDB / Pinecone）。
    *   **作用**：在每次调用大模型做重要决策时，根据相似度检索相关的深度记忆，作为 Prompt 的强约束。
*   **总结归档 (Archive)**：角色的完整生命流日志，仅供玩家/前端查阅，不参与 AI 计算。

## 3.2 睡前反思机制 (Reflection)
*   **触发条件**：游戏内的每日午夜（如 23:00）。
*   **处理逻辑**：
    1.  系统收集该角色当天的所有“感官层”与行为日志。
    2.  调用 LLM 进行一次批处理（总结提炼）：*"你今天经历了以上事件，请总结你对生活和其他村民的看法变化。"*
    3.  **记忆转化**：将提炼出的核心观念更新到角色的内在设定中，或者将其存入“深度记忆”。
    4.  **垃圾回收**：清空当天的感官层日志，准备迎接新的一天。
