# AI 小镇 - 星露谷物语风格 UI

> 创建时间：2026-02-26
> 状态：灵感阶段

## 核心概念

一个像素风格的 AI 小镇模拟器，每个居民都是独立的 AI 角色，拥有自己的性格、外观和行为模式。

## 核心功能

### 1. AI 角色系统
- 每个角色有独立的设定（性格、背景、喜好）
- 独特的像素外观
- 基于时间表的行为模式
- 记忆系统（短期/长期记忆）

### 2. 时间切片调度（Token 优化）
```
morning:  06:00  - 起床，规划一天
noon:     12:00  - 午间互动
evening:  18:00  - 傍晚社交
night:    22:00  - 总结日记
```
只在固定时间点触发 AI 对话，大幅降低 token 消耗。

### 3. 行为日志系统
- 记录每个角色的行动轨迹
- 显示内心独白（AI 生成）
- 可视化时间线

### 4. 上帝留言板
- 玩家作为"上帝"发布留言
- 角色可读取留言并做出反应
- 支持定向/全员广播
- 留言可设置过期时间

## Token 优化策略

1. **时间切片调度** - 只在固定时间点调用 AI
2. **批量处理** - 同场景角色共享上下文
3. **上下文压缩** - 只传最近 N 条相关日志
4. **设定缓存** - 性格模板预处理
5. **分级模型** - 简单行为用便宜模型

## NPC 性格与遗传系统 (Personality & Genetics System)

为了让每个 NPC 更加鲜活，我们设计了多维度的性格模型：

### 1. 性格的底层实现方式
性格不能仅仅是一段纯文本，需要结构化的数据来支撑 AI 的表现和游戏逻辑：
* **五维数值 (Big Five)**：使用大五人格（开放性、责任心、外向性、宜人性、神经质）的 0-100 数值。
* **特征标签 (Traits/Tags)**：如 "社恐", "工作狂", "贪财"。
* **系统提示词 (System Prompt)**：数值和标签会被动态转换为 LLM 的基础人设，例如：`"你是一个[外向评分 90]且具有[贪财]特征的村民，你的回应总是很热情并经常提到钱。"`

### 2. 遭遇大事件导致的性格改变 (动态演变)
NPC 是动态成长的，遇到重要事件（如灾难、玩家持续的帮助、亲属离去）会导致性格偏移：
* **事件权重阈值**：特殊事件会直接对"五维数值"产生巨大冲击（例如：破产导致神经质+30，乐观-40）。如果数值跨越阈值区间，特征标签也会演化（如从 "开朗" 变成 "抑郁"）。
* **核心记忆锚点 (Core Memory)**：大事件不仅改变数值，还会作为核心记忆永远出现在传递给 LLM 的上下文中，从而长久且自然地改变其行为和对话风格。

### 3. 新生 NPC 的遗传与变异 (繁衍系统)
小镇的生态应该是可以自我延续的，新生 NPC 的性格生成逻辑：
* **数值平均加权**：新生儿的五维数值取父母的加权平均值，并加入随机波动（±15%）以模拟先天差异。
* **特征遗传池**：父母的"特征标签"会进入遗传池，每个标签有一定概率（如 40%）传给下一代。
* **基因突变 (Mutation)**：有 5% 的低概率触发"显性突变"，新生儿会获得与父母完全相反或极其罕见的隐藏特征（例如生出一个"天才"或"捣蛋鬼"）。这为游戏增加了惊喜感。
